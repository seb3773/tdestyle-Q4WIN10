Q4WIN10 Widget Style for Trinity Desktop (TDE)

Q4WIN10 is a modern, lightweight, and flat Windows 10 & 11 inspired widget style plugin for the Trinity Desktop Environment (TDE / Q4OS).

Key Features:

  • Windows 10 & 11 Aesthetics: Modern flat widgets, clean outlines, smooth tabs and progress bars.
  • Windows 11 Rounded Mode: Subtle rounded controls and modern Win11 visual touches.
  • Dark Mode Support: Inverted high-contrast control rendering designed for dark desktop themes.
  • Menubar X11 Color Broadcast: Broadcasts menubar height and color to the window decoration for seamless header matching.
  • Dedicated Configuration Panel: Easily toggle Dark Mode and Windows 11 style in Trinity Control Center.
  • Ultra-Lightweight & Fast: Aggressively optimized C++ / TQt3 codebase with minimal CPU/RAM footprint.
  • Universal Compatibility: Fully compatible with all TDE R14.1.x versions (R14.1.0 to R14.1.6+).
